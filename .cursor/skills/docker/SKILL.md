# Docker Skill

## When to Use
- Criar ou modificar Dockerfile
- Ajustar docker-compose
- Configurar ambiente

## Instructions
- Use Dockerfile multi-stage
- Separar dev e production
- Não commitar secrets
- Usar `.env.example`
- Builds devem ser reprodutíveis
