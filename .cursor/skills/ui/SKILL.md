# UI & Design System Skill

## When to Use
- Criar componentes visuais
- Ajustar layout e responsividade
- Criar wrappers para shadcn/ui

## Instructions
- Use Tailwind como padrão
- Mobile-first
- Use `flex`, `grid` e `gap`
- Não use `@apply` para layouts complexos
- Não modifique arquivos em `components/ui`
- Crie wrappers ou componentes compostos
- Mantenha consistência visual
