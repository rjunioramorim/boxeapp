# E2E Testing Skill

## When to Use
- Validar fluxos críticos
- Testar formulários
- Testar autenticação
- Testar navegação e permissões

## Instructions
- Use Playwright
- Testar como usuário final
- Não mockar backend
- Usar ambiente isolado
- Priorizar fluxos críticos
- Evitar testes frágeis
