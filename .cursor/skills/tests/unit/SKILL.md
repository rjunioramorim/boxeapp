# Unit Testing Skill

## When to Use
- Testar funções puras
- Testar services
- Testar lógica de negócio isolada
- Validar regras sem dependência externa

## Instructions
- Use Vitest como test runner
- Testes devem ser rápidos e determinísticos
- Não acessar banco de dados
- Não renderizar componentes
- Use mocks explícitos
- Cada teste deve validar uma regra clara
- Evite testes genéricos ou redundantes
